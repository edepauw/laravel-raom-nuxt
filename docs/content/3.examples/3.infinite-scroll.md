Infinite scroll is just paging with **accumulation**: append each page to the list instead of replacing it, and stop once `pagination.last_page` is reached.

```vue [pages/reports/feed.vue]
<script setup lang="ts">
import type { ModelCollection } from 'laravel-raom-nuxt/runtime'
import { useInfiniteScroll } from '@vueuse/core'

const reports = ref<ModelCollection<Report>>([])
const nextPage = ref(1)
const lastPage = ref(1)
const pending = ref(false)

const canLoadMore = computed(() => nextPage.value <= lastPage.value)

async function loadMore() {
  if (pending.value || !canLoadMore.value) return
  pending.value = true
  try {
    const [data, pagination] = await Report.query()
      .include('creator')
      .orderBy('created_at', 'desc')
      .limit(25)
      .getPage(nextPage.value)

    reports.value = [...reports.value, ...data]  // accumulate, don't replace
    lastPage.value = pagination.last_page
    nextPage.value++
  }
  finally {
    pending.value = false
  }
}

await loadMore()  // first page during SSR

const el = ref<HTMLElement | null>(null)
useInfiniteScroll(el, loadMore, {
  distance: 200,
  canLoadMore: () => canLoadMore.value
})
</script>

<template>
  <div
    ref="el"
    class="h-[70vh] overflow-y-auto"
  >
    <article
      v-for="report in reports"
      :key="report.id"
    >
      <h3>{{ report.title }}</h3>
      <p class="text-muted">{{ report.creator?.name }}</p>
    </article>

    <p
      v-if="pending"
      class="text-muted"
    >
      Loading…
    </p>
    <p
      v-else-if="!canLoadMore"
      class="text-muted"
    >
      You've reached the end.
    </p>
  </div>
</template>
```

How it works:

- **`[...reports.value, ...data]`** appends the new page. Each `.getPage()` returns its own collection; spreading both into a fresh array grows the list.
- **`canLoadMore`** compares the next page against `pagination.last_page` from the tuple — that's how you know when to stop.
- The first page is fetched during SSR (top-level `await`); subsequent pages load on the client as the user scrolls.

::note
`useInfiniteScroll` here is the [VueUse](https://vueuse.org/core/useInfiniteScroll/) helper (any scroll trigger works — an `IntersectionObserver` sentinel, a "Load more" button, etc.). The package-specific part is `loadMore`: paginate with `.getPage()`, accumulate, and gate on `last_page`.
::
