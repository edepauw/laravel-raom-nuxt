A single editor that creates a new record or updates an existing one. The form is an **edit buffer**; the model is what you persist.

```vue [pages/reports/[id]/edit.vue]
<script setup lang="ts">
const route = useRoute()
const router = useRouter()

const isNew = computed(() => route.params.id === 'new')

// A fresh local instance to create, or an existing record to edit
const report = isNew.value
  ? Report.create({})
  : await Report.query().findByKey(Number(route.params.id))

// Keep form state separate from the model — apply it only on submit
const form = reactive({
  title: report.title ?? ''
})

const saving = ref(false)

async function submit() {
  saving.value = true
  try {
    report.title = form.title                 // apply the buffer to the model
    const { created } = await report.save()    // single round-trip; no-op if unchanged
    const id = isNew.value ? created[0] : route.params.id
    await router.push(`/reports/${id}`)
  }
  finally {
    saving.value = false
  }
}
</script>

<template>
  <form
    class="flex flex-col gap-3"
    @submit.prevent="submit"
  >
    <input
      v-model="form.title"
      placeholder="Title"
    >

    <button
      type="submit"
      :disabled="saving"
    >
      {{ isNew ? 'Create' : 'Save' }}
    </button>
  </form>
</template>
```

Key points:

- **`Report.create({})`** returns a *local* instance — nothing hits the backend until `.save()`.
- **Edit buffer:** bind the form to `form`, not to `report`. Direct assignment (`report.title = …`) is shared dirty state across every holder of that record; you don't want each keystroke leaking into other components. Apply the buffer on submit.
- **`save()`** returns `{ created, updated }`. On create, `created[0]` is the new id — handy for the redirect. On an instance with no dirty fields and no pending relation ops, `save()` is a **no-op** (no request).

## Creating with relations

Queue relation operations on the local instance before the first `save()` — parent and children travel in **one** request:

```ts
const report = Report.create({ title: 'Q2 review' })
report.creator.attach(currentUser.getKey())  // BelongsTo
report.subjects.attach(subjectAId)           // HasMany child
report.subjects.attach(subjectBId)
const { created } = await report.save()       // single round-trip
```
