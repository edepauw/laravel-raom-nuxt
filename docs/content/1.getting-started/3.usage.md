## Declare a model

Models extend `Model` and use the decorators from `laravel-raom-nuxt/runtime`. Relations are declared as **instance property initializers** — no `@Relation` decorator is needed.

```ts [app/models/Report.ts]
import {
  Model,
  Resource,
  Field,
  Key,
  HasMany,
  BelongsTo
} from 'laravel-raom-nuxt/runtime'

@Resource('reports', { limits: [1, 10, 25, 50] })
export class Report extends Model {
  @Key()
  @Field()
  id!: number

  @Field()
  title!: string

  @Field()
  created_at!: string

  status = BelongsTo(() => Status, 'status')
  creator = BelongsTo(() => User, 'creator')
  subjects = HasMany(() => Subject, 'subjects')
}
```

## Read

```ts
// Paginated list — .get() always returns a [collection, pagination] tuple
const [reports, pagination] = await Report.query()
  .include('creator')
  .limit(10)
  .get()

// Fetch by primary key — throws if not found
const report = await Report.query()
  .include('creator')
  .findByKey(id)
```

After `.include('creator')`, the relation is a plain property on the instance — always optional-chain it:

```ts
report.creator?.name
```

## Create & update

```ts
// Create, attaching relations in the same round-trip
const report = Report.create({ title: 'Q2 review' })
report.creator.attach(currentUser.getKey())
report.subjects.attach(subjectId)
const { created } = await report.save()

// Update: fetch, mutate, save
const existing = await Report.query().findByKey(id)
existing.title = 'New title'
await existing.save()
```

## Delete

```ts
await report.delete()
```
